# AI 채찍효과 버블 미터

AI 투자 붐의 버블 정도를 0~100으로 재는 대시보드의 소스와 데이터입니다. 공급망 채찍효과(Lee·Padmanabhan·Whang, 1997)의 틀로 최종수요에서 금융시장까지 7개 마디를 측정합니다.

- 대시보드: https://claude.ai/artifact/HL5dsx4fuyUCnRSvzaJxqu (Claude Dashboard 아티팩트, 비공개)
- 최초 분석: 2026년 10월 24일 19시 15분 KST, 데이터 기준일 2026년 10월 23일
- 최초 종합 점수: 71.0 (버블 형성 구간)
- 출발점: 서울대학교 「주문이 폭주할 때 오히려 의심해야 하는 이유」(스탠퍼드 황승진 교수). 자막은 수집하지 못해 타임라인·원 논문·댓글로 재구성했습니다.

투자 권유가 아닙니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 대시보드 페이지. Dashboard 아티팩트 타입 안에서 돌아가며 `dash`(데이터 API)와 `d3` 전역에 의존하므로 단독으로 열면 동작하지 않습니다. |
| `data/indicators.json` | 15개 지표의 원값, 정상·극단 기준, 0~100 점수, 신뢰도, 출처 |
| `data/dram.json` | 분기별 DRAM 계약가 상승률 범위 |
| `data/kospi.json` | KOSPI 종가 |
| `data/timeline.json` | AI 사이클과 닷컴 사이클 주요 사건 |
| `data/score_log.json` | 갱신마다 쌓이는 종합·마디별 점수 기록 |
| `data/chain.json` | 채찍효과 증폭 예시(영상 댓글 전언, 미검증) |
| `data/cycle_curve.json` | Rodrigue 버블 단계 개념 곡선(실측 아님) |
| `data/mem_phases.json` | 메모리 사이클 5단계 정의 |
| `scripts/build_indicators.py` | 최초 지표·DRAM·KOSPI·증폭 예시 파일 생성 |
| `scripts/build_cycle.py` | 최초 타임라인·곡선·단계 정의 파일 생성 |
| `REFRESH.md` | 주간 자동 갱신 절차 |

`score_log.json`은 스크립트가 만들지 않습니다. 갱신할 때마다 한 줄씩 늘어나는 기록입니다.

## 점수 계산

1. 지표 점수
   - 정량 지표: `(원값 − 정상) ÷ (극단 − 정상) × 100`을 0~100으로 자릅니다.
   - 정성 지표 4개(중복 주문, DRAM 감속, 버블 인식, 신용융자): 규칙을 밝힌 판단 점수입니다.
2. 마디 점수: 같은 마디 안 지표 점수의 평균
3. 종합 점수: 마디 가중 평균. 가중치는 최종수요 20, 주문 15, 상류 가격 15, 한국 말단 10, 밸류에이션 15, 심리 10, 레버리지 15입니다.
4. 구간: 0~20 정상, 20~40 확장, 40~60 과열 초기, 60~80 버블 형성, 80~100 버블 극단

정상·극단 기준 다수는 분석자 가정입니다. 대시보드의 민감도 패널이 어느 가정이 결론을 움직이는지 보여줍니다.
