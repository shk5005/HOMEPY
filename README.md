# 🧞 지니 (Genie) — 주식투자비서

> **AI 강제 차단 시스템 : 행동경제학 헷지**
> 지니는 종목을 대신 골라주지 않습니다. **당신이 실수하지 못하게 막습니다.**

참조 자료 *「AI 투자 3단계 Chain of Questions」* 의 화면 설계와 프롬프트 체계를
그대로 구현한 정적 웹 앱입니다. 빌드 도구·서버·API 키가 필요 없습니다.

```bash
python3 -m http.server 8000        # 앱 (정적 서버면 무엇이든)
node server/quote-proxy.mjs        # 시세 자동 조회 (선택)
# → http://localhost:8000
```

시세 프록시는 **선택 사항**입니다. 실행하지 않으면 시세를 수동 입력하면 되고,
나머지 기능은 그대로 동작합니다.

### 단일 HTML로 묶기

```bash
npm install          # esbuild (빌드에만 필요)
node build.mjs
```

- `dist/genie.html` — 완결된 HTML 문서. **파일을 그냥 더블클릭해도 실행**됩니다.
- `dist/genie.artifact.html` — body 내용만. 호스팅/Artifact 발행용.

ES 모듈 8개와 CSS가 파일 하나로 합쳐지고 외부 요청이 0건이 됩니다.
단일 빌드에서는 로컬 프록시를 쓸 수 없으므로 **시세 자동 조회가 꺼지고
수동 입력 안내로 대체**되며, 프롬프트 `.txt` 저장 버튼도 빠집니다(복사는 그대로).

## 핵심 컨셉 — 함정 5가지를 구조적으로 차단

| # | 일반 투자자가 빠지는 함정 | 지니의 강제 차단 | 구현 위치 |
|---|---------------------------|------------------|-----------|
| ① | 기준 없이 '추천해줘' | 거장 기준 강제 설정 | `views-core.js` → 종목 발굴 |
| ② | 하나의 AI만 믿기 | 3개의 AI로 교차 검증 | `calc.js` → `crossValidate()` |
| ③ | 하나의 지표만 보기 | PER·PBR·DCF 가중 + 안전마진 20% | `calc.js` → `relativeValue()` |
| ④ | 환각·출처 없는 수치 | 신뢰성 룰 5가지 + 시세 앵커 | `prompts.js` → `guardBlock()` |
| ⑤ | 손절가 없이 매수 | Bull/Base/Bear + 손절가 먼저 | `calc.js` → `priceGuide()` |

## 앱 구조 — 6단계 파이프라인

```
① 종목 발굴 ─→ ② 교차 검증 ─→ ③ 심층 분석 ─→ ④ 밸류에이션 ─→ ⑤ 리스크 ─→ ⑥ 포트폴리오
   RICE          3-AI 교집합      STEP 1~5        안전마진        시나리오      차등배분
   프롬프트      + 근거 충돌     WHAT→WHEN       다각 멀티플     손절 먼저    Core-Satellite
                                                                       └─→ 🔗 Chain of Questions
```

### ① 종목 발굴 — RICE 프롬프트 생성
섹터 × 스타일 × 스크리닝 필터 × 기간 × 목표수익률을 조합해
**R**ole · **I**nstruction · **C**ontext · **E**xample 프롬프트를 자동 생성합니다.
"괜찮은 주식 추천해줘"를 재현 가능한 질문으로 바꾸는 단계입니다.

### ② 교차 검증 — 3-AI 합의
ChatGPT / Claude / Perplexity 답변을 그대로 붙여넣으면
번호목록·마크다운 표·볼드·불릿 패턴에서 종목명을 추출해 교집합을 계산합니다.
**3/3 만장일치 · 2/3 합의 · 단독 추천**으로 분류하며, API 호출이 없습니다.

### ③ 심층 분석 — STEP 1~5 (+ 보조 4종)
| 단계 | 질문 | 내용 |
|------|------|------|
| STEP 1 · 종합 SWOT | WHAT | 뭐 하는 회사인가 |
| STEP 2 · 실적 분석 | WHY | 비즈니스가 진짜인가 |
| STEP 3 · 재무 분석 | HOW | 숫자가 견고한가 (듀퐁 3분해) |
| STEP 4 · 밸류에이션 | HOW MUCH | 지금 얼마짜리인가 |
| STEP 5 · 기술적 분석 | WHEN | 지금이 타이밍인가 |
| 추가 · 질적 분석 | MOAT | 모닝스타 해자 5분류 |
| 추가 · 공시(DART) | NEWS | 최근 자본 이벤트 |
| 추가 · 어닝콜 | TONE | 경영진 톤 변화 |
| 대안 · ETF | ALT | 개별주 부담 시 대안 |

**시세 앵커**: 종목별 현재가·PER·PBR·시총·52주 밴드가
프롬프트 안에 조회 시점과 함께 박혀, AI의 과거 학습값 사용을 차단합니다.
수동 입력하거나, 아래 시세 프록시로 자동 조회할 수 있습니다.

### ④ 밸류에이션 — 다각 멀티플 + 안전마진
PER · PBR · EV/EBITDA · PSR · Rule of 40 · PEG 6개 멀티플별 적정주가를
가중 종합하고, 안전마진(10~40%)을 적용한 매수가를 산출합니다.
PEG 계산기와 듀퐁 3분해 계산기를 함께 제공합니다.

### ⑤ 리스크 — 시나리오 · 손익관리
Bull(30%) / Base(50%) / Bear(20%) 목표가로 **확률 가중 기대수익률**을 계산하고,
손절 −20% · 1차 익절 +15% · 2차 익절 +30% 기준으로 종목별 가격 구간과
**Risk/Reward 비율**을 판정합니다. 1:2 미만이면 "투자 부적합"으로 표시됩니다.

### ⑥ 포트폴리오 — 투자점수 기반 차등배분
성장 30 + 해자 30 + 밸류에이션 20 + 모멘텀 20 = 100점으로 채점하면
**Core-Satellite** 밴드(핵심 35~40% / 주력 20~25% / 관망 10~15%)에 자동 배정하고,
잔여분을 현금 버퍼로 남깁니다.

### 🔗 Chain of Questions — 3단계 질문 사슬
1. **국면 판정 + 확신도(0~100) 요구** — 표 형식 근거와 확신도를 강제
2. **반대 근거 강제 요구** — AI의 낙관 편향을 깨는 반증 요구
3. **감시 지표 & 킬 스위치** — 매달 확인 가능한 지표 3개 + 행동 지침 표

## 파일 구조

```
index.html                  앱 셸 (사이드바 + 라우팅 컨테이너)
assets/

└── js/
    ├── data.js             도메인 상수 — 섹터·해자·멀티플·신뢰성 룰·배분 밴드
    ├── calc.js             계산 엔진 (순수 함수) — 밸류에이션·시나리오·점수·배분·종목추출
    ├── prompts.js          RICE 프롬프트 빌더 — 전 단계 + Chain of Questions
    ├── store.js            상태 관리 + localStorage 영속화
    ├── ui.js               DOM 헬퍼 — 칩·표·프롬프트 박스·토스트 (XSS 이스케이프 포함)
    ├── quotes.js           시세 클라이언트 (프록시 호출 + 수동 폴백)
    ├── views-core.js       대시보드 · 종목 발굴 · 교차 검증
    ├── views-analysis.js   심층 분석 · 밸류에이션 · 리스크 · 포트폴리오 · 체인
    └── app.js              라우터 + 이벤트 위임 컨트롤러

└── providers/
    ├── _extract.mjs          응답 형태 변화에 견디는 값 추출 (공용)
    ├── toss-open.mjs         토스증권 오픈 API 어댑터 (API 키)
    └── toss.mjs              토스증권 WTS 어댑터 (비공식, 키 불필요)
```

**의존성 없음.** ES 모듈 + 바닐라 JS. 번들러·프레임워크·외부 CDN을 쓰지 않습니다.

## 시세 자동 조회 (토스증권)

```bash
cp .env.example .env                           # GENIE_TOSS_API_KEY 를 채운다
node server/quote-proxy.mjs                    # 127.0.0.1:8787
node server/quote-proxy.mjs --probe 005930     # 요청·응답 진단
```

키가 있으면 **토스증권 오픈 API**를, 없으면 비공식 WTS 경로를 씁니다.
키는 `.env`(gitignore 대상)에만 두며 프록시 프로세스 밖으로 나가지 않습니다 —
브라우저로 내려가지 않고, 로그에는 마스킹되어 출력됩니다.

앱의 **③ 심층 분석 → 분석 대상 종목**에서 `🔍 토스 검색`으로 종목을 찾아 담고,
`🔄 시세 자동 조회`를 누르면 현재가·등락·PER·PBR·시총·52주 밴드와
조회 시점이 한 번에 채워집니다.

### ⚠️ 알아둬야 할 제약

> 키가 **없을 때** 쓰이는 WTS 경로는 토스 웹 트레이딩이 내부적으로 사용하는
> **비공식·비문서화 엔드포인트**입니다. 예고 없이 바뀌거나 차단될 수 있습니다.
> 오픈 API 키를 설정하면 그쪽을 우선 사용합니다.
>
> 오픈 API 어댑터의 엔드포인트 경로·인증 방식은 공식 문서를 확인하지 못한 채
> 기본값으로 두었습니다. 어긋나면 코드가 아니라 `.env` 값을 고치면 됩니다
> ([docs/QUOTES.md](docs/QUOTES.md)).

- **로컬 프록시가 반드시 필요합니다.** 해당 엔드포인트는 CORS 허용 헤더를 주지 않아
  브라우저에서 직접 호출할 수 없습니다. 프록시는 `127.0.0.1` 에만 바인딩하며
  등록된 프로바이더 호스트로만 요청합니다(열린 프록시가 되지 않도록).
- **실패해도 앱은 멈추지 않습니다.** 프록시가 꺼져 있거나 상대가 막으면
  배지가 🟡/🔴 로 바뀌고 수동 입력으로 되돌아갑니다. 이미 입력된 시세는 보존됩니다.
- **응답 형태가 바뀌면** `--probe` 로 원본 JSON을 확인하고
  `server/providers/toss.mjs` 의 `FIELD_MAP` 에 키를 추가하면 됩니다.
  자세한 내용은 [docs/QUOTES.md](docs/QUOTES.md).

## 데이터 취급

- 모든 입력(종목·시세·점수·AI 답변)은 **브라우저 localStorage에만** 저장되며 외부로 전송되지 않습니다.
- 시세 프록시는 로컬에서만 돌며, 조회한 값도 브라우저에만 저장됩니다.
  프록시는 인증 정보를 다루지 않습니다.
- 조회된 현재가는 매매에 쓰이지 않고, AI에게 넘기는 **기준점(앵커)** 으로만 쓰입니다.
- 사이드바 **전체 초기화**로 저장된 상태를 지울 수 있습니다.

## ⚠️ 면책

지니는 투자 자문 도구가 아닙니다. 생성된 프롬프트와 계산 결과는 의사결정 보조 자료이며,
표시되는 모든 수치는 사용자가 입력했거나 AI 답변에서 나온 값입니다.
반드시 거래소·DART 원문으로 교차 확인하세요. **최종 투자 판단과 그 책임은 투자자 본인에게 있습니다.**
