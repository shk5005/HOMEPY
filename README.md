# 🧞 지니 (Genie) — 주식투자비서

> **AI 강제 차단 시스템 : 행동경제학 헷지**
> 지니는 종목을 대신 골라주지 않습니다. **당신이 실수하지 못하게 막습니다.**

참조 자료 *「AI 투자 3단계 Chain of Questions」* 의 화면 설계와 프롬프트 체계를
그대로 구현한 정적 웹 앱입니다. 빌드 도구·서버·API 키가 필요 없습니다.

```bash
python3 -m http.server 8000   # 또는 아무 정적 서버
# → http://localhost:8000
```

## 핵심 컨셉 — 함정 5가지를 구조적으로 차단

| # | 일반 투자자가 빠지는 함정 | 지니의 강제 차단 | 구현 위치 |
|---|---------------------------|------------------|-----------|
| ① | 기준 없이 '추천해줘' | 거장 기준 강제 설정 | `views-core.js` → 종목 발굴 |
| ② | 하나의 AI만 믿기 | 3개의 AI로 교차 검증 | `calc.js` → `crossValidate()` |
| ③ | 하나의 지표만 보기 | PER·PBR·DCF 가중 + 안전마진 20% | `calc.js` → `relativeValue()` |
| ④ | 환각·출처 없는 수치 | 신뢰성 룰 5가지 + 시세 앵커 | `prompts.js` → `guardBlock()` |
| ⑤ | 손절가 없이 매수 | Bull/Base/Bear + 손절가 먼저 | `calc.js` → `priceGuide()` |

## 앱 구조 — 6단계 파이프라인

```
① 종목 발굴 ─→ ② 교차 검증 ─→ ③ 심층 분석 ─→ ④ 밸류에이션 ─→ ⑤ 리스크 ─→ ⑥ 포트폴리오
   RICE          3-AI 교집합      STEP 1~5        안전마진        시나리오      차등배분
   프롬프트      + 근거 충돌     WHAT→WHEN       다각 멀티플     손절 먼저    Core-Satellite
                                                                       └─→ 🔗 Chain of Questions
```

### ① 종목 발굴 — RICE 프롬프트 생성
섹터 × 스타일 × 스크리닝 필터 × 기간 × 목표수익률을 조합해
**R**ole · **I**nstruction · **C**ontext · **E**xample 프롬프트를 자동 생성합니다.
"괜찮은 주식 추천해줘"를 재현 가능한 질문으로 바꾸는 단계입니다.

### ② 교차 검증 — 3-AI 합의
ChatGPT / Claude / Perplexity 답변을 그대로 붙여넣으면
번호목록·마크다운 표·볼드·불릿 패턴에서 종목명을 추출해 교집합을 계산합니다.
**3/3 만장일치 · 2/3 합의 · 단독 추천**으로 분류하며, API 호출이 없습니다.

### ③ 심층 분석 — STEP 1~5 (+ 보조 4종)
| 단계 | 질문 | 내용 |
|------|------|------|
| STEP 1 · 종합 SWOT | WHAT | 뭐 하는 회사인가 |
| STEP 2 · 실적 분석 | WHY | 비즈니스가 진짜인가 |
| STEP 3 · 재무 분석 | HOW | 숫자가 견고한가 (듀퐁 3분해) |
| STEP 4 · 밸류에이션 | HOW MUCH | 지금 얼마짜리인가 |
| STEP 5 · 기술적 분석 | WHEN | 지금이 타이밍인가 |
| 추가 · 질적 분석 | MOAT | 모닝스타 해자 5분류 |
| 추가 · 공시(DART) | NEWS | 최근 자본 이벤트 |
| 추가 · 어닝콜 | TONE | 경영진 톤 변화 |
| 대안 · ETF | ALT | 개별주 부담 시 대안 |

**시세 앵커**: 종목별 현재가·PER·PBR·시총·52주 밴드를 입력하면
프롬프트 안에 조회 시점과 함께 박혀, AI의 과거 학습값 사용을 차단합니다.

### ④ 밸류에이션 — 다각 멀티플 + 안전마진
PER · PBR · EV/EBITDA · PSR · Rule of 40 · PEG 6개 멀티플별 적정주가를
가중 종합하고, 안전마진(10~40%)을 적용한 매수가를 산출합니다.
PEG 계산기와 듀퐁 3분해 계산기를 함께 제공합니다.

### ⑤ 리스크 — 시나리오 · 손익관리
Bull(30%) / Base(50%) / Bear(20%) 목표가로 **확률 가중 기대수익률**을 계산하고,
손절 −20% · 1차 익절 +15% · 2차 익절 +30% 기준으로 종목별 가격 구간과
**Risk/Reward 비율**을 판정합니다. 1:2 미만이면 "투자 부적합"으로 표시됩니다.

### ⑥ 포트폴리오 — 투자점수 기반 차등배분
성장 30 + 해자 30 + 밸류에이션 20 + 모멘텀 20 = 100점으로 채점하면
**Core-Satellite** 밴드(핵심 35~40% / 주력 20~25% / 관망 10~15%)에 자동 배정하고,
잔여분을 현금 버퍼로 남깁니다.

### 🔗 Chain of Questions — 3단계 질문 사슬
1. **국면 판정 + 확신도(0~100) 요구** — 표 형식 근거와 확신도를 강제
2. **반대 근거 강제 요구** — AI의 낙관 편향을 깨는 반증 요구
3. **감시 지표 & 킬 스위치** — 매달 확인 가능한 지표 3개 + 행동 지침 표

## 파일 구조

```
index.html                  앱 셸 (사이드바 + 라우팅 컨테이너)

    ├── calc.js             계산 엔진 (순수 함수) — 밸류에이션·시나리오·점수·배분·종목추출

    ├── store.js            상태 관리 + localStorage 영속화
    ├── ui.js               DOM 헬퍼 — 칩·표·프롬프트 박스·토스트 (XSS 이스케이프 포함)
```

## 데이터 취급

- 모든 입력(종목·시세·점수·AI 답변)은 **브라우저 localStorage에만** 저장되며 외부로 전송되지 않습니다.
- 지니는 시세를 조회하지 않습니다. 현재가는 사용자가 직접 입력하며, 그 값은 AI에게 넘기는
  **기준점(앵커)** 으로만 쓰입니다.
- 사이드바 **전체 초기화**로 저장된 상태를 지울 수 있습니다.

## ⚠️ 면책

지니는 투자 자문 도구가 아닙니다. 생성된 프롬프트와 계산 결과는 의사결정 보조 자료이며,
표시되는 모든 수치는 사용자가 입력했거나 AI 답변에서 나온 값입니다.
반드시 거래소·DART 원문으로 교차 확인하세요. **최종 투자 판단과 그 책임은 투자자 본인에게 있습니다.**
