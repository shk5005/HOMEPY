# Intent: 아파트 실거래가 이상거래 탐지

- **Date:** 2026-10-26

## Problem

국토부 실거래가에는 직거래, 특수관계인 간 거래, 신고 후 해제(취소)된 거래가 정상 거래와 섞여 있다.
이 거래들이 단지별 시세 판단을 왜곡한다. 지금은 엑셀에서 수작업으로 걸러내고 있어
시간이 오래 걸리고, 사람마다 기준이 달라 같은 단지라도 결과가 다르게 나온다.

## Proposed outcome

- 단지·평형별로 '정상 거래 기준 시세'를 자동 산출한다.
- 거래 건마다 이상거래 플래그와 그 사유(예: 직거래, 해제, 통계적 이상치)를 붙인다.
- 같은 입력이면 누가 돌려도 같은 결과가 나온다(기준의 재현성).
- 분석 시간을 단축한다. 현재 소요 시간(단지당 약 30분, 추정치)을 먼저 실측해 기준선으로 삼는다.
- 플래그 품질은 표본 100건을 수기로 검증해 측정한다.

## Affected users and systems

- 사용자: 본인(분석가), 향후 투자 자문 고객
- 시스템/데이터: 국토부 아파트 매매 실거래가 공개 데이터, 한국부동산원 시세(비교용),
  (선택) 카카오 부동산 데이터

## Constraints

- 신고 시차: 거래 신고는 계약일로부터 30일 이내, 해제 신고는 해제 확정일로부터 30일 이내다.
  따라서 최근 1~2개월 데이터는 미확정으로 취급한다.
- 공공데이터 API 호출 한도 안에서 동작해야 한다.
- 개인정보가 포함되지 않은 공개 데이터만 사용한다.
- 이상거래 플래그는 '통계적 이상치 또는 비정형 거래'라는 뜻일 뿐이다. '불법 거래'로 표기하거나 암시하지 않는다.

## Open questions

- [ ] 이상치 기준: 동일 단지·평형 중위가 대비 ±N%로 할지, 회귀 잔차 기반으로 할지? N은 얼마로 할지?
- [ ] 층·향·동 보정에 쓸 데이터가 있는가? 없으면 층 정보만으로 보정할 수 있는가?
- [ ] 직거래를 일괄 제외할지, 가중치만 낮출지?
- [ ] 공개 데이터에 거래유형(직거래/중개거래)과 해제 여부 필드가 실제로 제공되는가? 제공 시점과 결측률은?
- [ ] 거래가 적은 소형 단지(예: 분기 3건 미만)는 어떻게 처리할지? 인근 단지와 묶을지, 판정을 보류할지?
- [ ] 비교 기준 기간: 직전 3개월, 6개월, 12개월 중 무엇으로 할지?
- [ ] 결과물 형태: 대시보드, 엑셀 리포트, API 중 무엇이 먼저 필요한가?
