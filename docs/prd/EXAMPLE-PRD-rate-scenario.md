## 0. 제품 정의

"금리가 오를지 내릴지 맞히는 예측 모델"이 아니라,
**"어떤 조건이 관측되면 무엇을 하는가"를 사전에 확정해 두는 조건반사 규칙집**이다.

이 구분이 이 PRD의 존재 이유다. 예측은 빗나가지만 규칙은 실행된다.

## 1. 문제 정의 (S1)

**한 문장**
> 레버리지를 보유한 개인 투자자가 `[추정]`, 전쟁발 공급충격으로 금리 방향이 불확실한 국면에서, 상승·하락 어느 쪽에도 사전 정의된 행동규칙이 없어, 뉴스에 사후 반응하다가 최악의 사분면(스태그플레이션·침체)에서 대응 시점을 놓친다.

- 현행 대체 수단: 뉴스 모니터링 + 직관적 판단 `[추정]` — 가용성 휴리스틱에 구조적으로 취약
- 1차 사용자: 본인 1인 (부동산 중심 자산 보유) `[미검증]` — 자산 구성 미확인
- 사용 빈도: 주 1회 정기 + 이벤트 트리거(FOMC·금통위·CPI·유가 임계)
- 실패 허용도: **치명적** — 레버리지 자산은 되돌리기 비용이 크고 유동성이 낮다

**문제의 근본 원인 (5 Why 축약)**
금리 방향을 모른다 → 방향을 맞히려 한다 → 맞히지 못한다 → 판단을 유보한다 → 조건이 바뀌어도 행동이 없다 → **무행동이 곧 최대 리스크 포지션**이 된다.

## 2. 성공 기준 (S2)

| 지표 | 현재 기준선 | 목표 | 측정 방법 | 측정 시점 |
|---|---|---|---|---|
| 사분면 전환 인지 → 규칙 발동 시차 | **없음(무규칙 상태)** `[확인]` | 5영업일 이내 | 트리거 로그 | 이벤트 발생 시 |
| 최대낙폭(MDD) 한도 | **확인 불가** (포트폴리오 미상) → OQ-01 | 사용자 지정 필요 | 월말 평가액 | 월 1회 |
| 강제 청산·연체 발생 | 0건 | 0건 유지 | 대출 계좌 | 상시 |
| 규칙 준수율 | 없음 | 100% | 의사결정 로그 | 분기 |

- **Kill Switch (이 PRD를 폐기할 조건)**: 규칙을 3회 연속 자의적으로 무시할 경우 → 규칙집이 작동하지 않는다는 뜻이므로 폐기하고 "레버리지 축소" 단일 규칙으로 단순화.
- 비판: **기준선이 없는 목표치는 검증 불가능한 희망이다.** MDD 목표는 OQ-01 해소 전까지 공란으로 둔다. 추정치로 채우지 않는다.

## 3. 범위 (S3)

**In scope (Must)**
- 사분면 판정 규칙, 자산군별 노출 조정 규칙, 트리거 임계값, 모니터링 항목 정의

**Out of scope (이번엔 제외)**
- 개별 종목·단지 선정, 세무 최적화, 매물 현장 실사, 대출 상품 비교

**Non-goals (명시적으로 하지 않을 것)** — 범위 팽창 방지의 핵심
- **NG-1**: 유가·전쟁 종결 시점을 예측하지 않는다.
- **NG-2**: 금리 방향 자체를 맞히려 하지 않는다.
- **NG-3**: 시나리오별 수익 극대화를 추구하지 않는다. **생존과 선택권 유지가 목적함수다.**
- **NG-4**: 전쟁 종결(B-1) 시나리오에 대한 대규모 선제 베팅을 하지 않는다. 손실 한정 방식만 허용.
- **NG-5**: 과거 2022~23 인상기 대응을 그대로 복제하지 않는다(앵커링 차단).

**마감 제약**: 2026-09-16 FOMC, 10월 한은 금통위 `[확인]`. 이 두 이벤트 전에 F-01·F-02 규칙 확정 필요.

### F-01 사분면 판정 로직 (핵심)

| | 원인 = 인플레(공급충격) | 원인 = 성장(수요) |
|---|---|---|
| **금리 ↑** | **A. 스태그플레이션형** ← 현재 위치 `[확인 기반 판정]` | A'. 골디락스형 |

| R-05 | **Black Swan** | 호르무즈 완전 봉쇄 → 유가 $150+ | 전 자산 동시 하락 | 통항량(확인 불가) | 현금·달러 최저선 사전 확보 |

**내가 틀릴 가장 큰 이유**: 사분면 판정이 사후적으로만 명확해질 수 있다. 실시간으로는 A와 B의 경계가 모호하며, 그 모호 구간에서 규칙이 진동(whipsaw)할 수 있다.

**편향 점검**: 확증편향(부동산 보유자는 인하 근거만 수집) / 가용성 휴리스틱(분당 헤드라인) / 앵커링(2022~23 경험 대입) / 생존자 편향(오른 지역만 표본) / 손실회피(고점 대비 하락분 미실현) / 기저율 무시("전쟁은 끝난다" vs 7개월 교착)

## 7. 수용 기준 & 마일스톤 (S7)

### AC — Given / When / Then

- **AC-F01**: Given 주간 점검일, When 유가·CPI·고용·스프레드 4개 입력이 모두 갱신됨, Then 사분면 판정을 기록하고 전 주 대비 변화 여부를 로그에 남긴다(무변화도 기록).
- **AC-F02**: Given 브렌트 3거래일 연속 $100 이상, When 미 10년물 4.9% 초과, Then 5영업일 내 신규 레버리지 0으로 동결하고 기존 LTV 축소 착수. *(임계값은 ASM-02, 사용자 확정 필요)*
- **AC-F03**: Given 원/달러 1,400원 상향 돌파, Then 달러 자산 목표비중까지 **3회 분할** 매수 개시. 단 1회차는 돌파 확인 후 D+3 이내.
- **AC-F04**: Given 침체 신호 3종(미 고용 악화 / 신용스프레드 확대 / 유가 고공 유지) 중 **2개 이상 동시 관측**, Then 현금흐름 미발생 부동산부터 매도 우선순위 리스트를 실행한다. 금리 하락은 매수 신호로 해석하지 않는다.
- **AC-F05**: Given 미 10년물 5.0% 돌파, Then 장기채 분할 진입 1차 실행(총 목표의 1/3 이하). 몰빵 금지.
- **AC-F06**: Given 경매 낙찰가율이 3개월 연속 하락, Then 자금 준비 단계로 전환(입찰 아님). 진입은 2027년 이후 별도 판정.
- **AC-F07**: Given 어떤 규칙이든 발동 직전, When 실행 전, Then §6 편향 6종 체크리스트를 통과해야 실행한다.
