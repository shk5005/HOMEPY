S1문제 정의

한 문장 문제 정의
레버리지를 보유한 개인 투자자가 추정, 전쟁발 공급충격으로 금리 방향이 불확실한 국면에서, 상승·하락 어느 쪽에도 사전 정의된 행동규칙이 없어, 뉴스에 사후 반응하다가 최악의 사분면(스태그플레이션·침체)에서 대응 시점을 놓친다.
항목내용
현행 대체 수단뉴스 모니터링 + 직관적 판단 추정 — 가용성 휴리스틱에 구조적으로 취약
1차 사용자본인 1인 (부동산 중심 자산 보유) 미검증 — 자산 구성 미확인
사용 빈도주 1회 정기 점검 + 이벤트 트리거(FOMC·금통위·CPI·유가 임계)
실패 허용도치명적 — 레버리지 자산은 되돌리기 비용이 크고 유동성이 낮음
근본 원인 (5 Why 축약)

금리 방향을 모른다 → 방향을 맞히려 한다 → 맞히지 못한다 → 판단을 유보한다 → 조건이 바뀌어도 행동이 없다 → 무행동이 곧 최대 리스크 포지션이 된다.

규칙을 3회 연속 자의적으로 무시할 경우. 규칙집이 작동하지 않는다는 뜻이므로 폐기하고 “레버리지 축소” 단일 규칙으로 단순화한다.

S3범위

In scope (Must)

사분면 판정 규칙 · 자산군별 노출 조정 규칙 · 트리거 임계값 정의 · 모니터링 항목 정의

Out of scope (이번엔 제외)

개별 종목·단지 선정 · 세무 최적화 · 매물 현장 실사 · 대출 상품 비교

Non-goals — 명시적으로 하지 않을 것 (범위 팽창 방지의 핵심)

  • NG-1 유가·전쟁 종결 시점을 예측하지 않는다.
  • NG-2 금리 방향 자체를 맞히려 하지 않는다.
  • NG-3 시나리오별 수익 극대화를 추구하지 않는다. 목적함수는 생존과 선택권 유지다.
  • NG-4 전쟁 종결(B-1) 시나리오에 대규모 선제 베팅을 하지 않는다. 손실이 한정된 방식만 허용한다.
  • NG-5 2022~23년 인상기 대응을 그대로 복제하지 않는다 (앵커링 차단).

F-01 사분면 판정 로직 — 금리 2분법을 2×2로 대체

원인 = 인플레이션 (공급충격) 원인 = 성장 (수요)
금리 ↑ A. 스태그플레이션형 긴축현재 위치 유가↑ → CPI↑ → Fed·한은 인상. 주식·채권·부동산 동반 압박. A′. 골디락스형 인상 성장이 좋아 금리↑. 주식 우호, 부동산 중립. 현재 확률 낮음.
금리 ↓ B′. 인플레 하 정치적 인하 연준 독립성 훼손 시. 인플레 기대 이탈 → 금·달러 외 전 자산 위험. B. 침체형 인하 고유가 → 실질소득 감소 → 침체. 장기채·현금만 승리. 부동산 최악 구간.
핵심 판정 원칙

사분면 4개 중 3개가 위험자산에 불리하다. 따라서 금리 하락을 단일 신호로 호재 판정하지 않는다. 판정 입력은 유가 방향 × CPI 방향 × 고용·신용스프레드 방향의 조합이다.

S7수용 기준 (AC) & 마일스톤

Given(주어진 상태) / When(관측) / Then(행동). 규칙이 실행 가능한 문장으로 쓰이지 않으면 규칙이 아니다.

AC-F01 · 사분면 판정 Given 주간 점검일, When 유가·CPI·고용·신용스프레드 4개 입력이 모두 갱신됨, Then 사분면 판정을 기록하고 전주 대비 변화 여부를 로그에 남긴다. 무변화도 기록한다.
AC-F02 · 레버리지 상한 Given 브렌트 3거래일 연속 $100 이상, When 미 10년물 4.9% 초과, Then 5영업일 내 신규 레버리지를 0으로 동결하고 기존 LTV 축소에 착수한다. (임계값은 ASM-02 — 사용자 확정 필요)
AC-F03 · 통화 헤지 Given 원/달러 1,400원 상향 돌파, Then 달러 자산을 목표비중까지 3회 분할 매수한다. 1회차는 돌파 확인 후 D+3 이내.
AC-F04 · 부동산 매도 우선순위 Given 침체 신호 3종(미 고용 악화 / 신용스프레드 확대 / 유가 고공 유지) 중 2개 이상 동시 관측, Then 현금흐름이 발생하지 않는 부동산부터 매도 우선순위 리스트를 실행한다. 이 구간에서 금리 하락을 매수 신호로 해석하지 않는다.
AC-F05 · 듀레이션 Given 미 10년물 5.0% 돌파, Then 장기채 분할 진입 1차를 실행한다(총 목표의 1/3 이하). 몰빵 금지.
AC-F06 · 경매 준비 Given 경매 낙찰가율이 3개월 연속 하락, Then 자금 준비 단계로 전환한다(입찰 아님). 실제 진입은 2027년 이후 별도 판정.
AC-F07 · 편향 게이트 Given 어떤 규칙이든 발동 직전, When 실행 전, Then S6의 편향 6종 체크리스트를 통과해야만 실행한다.
